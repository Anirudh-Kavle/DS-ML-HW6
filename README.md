# Homework 6: Tree-based methods on the APS Failure data, ISLR 6.6.3, 6.6.5, 8.4.5 and 9.7.3

- `notebook/Kavle_Anirudh_HW6.ipynb`: solutions to Questions 1, 2, 3, 4 and 5
- `data/`: UCI APS Failure at Scania Trucks dataset (the training and test CSV files)

To run: `pip install -r requirements.txt`, open the notebook from the `notebook/` folder and use Run All. It reads the data from `../data/`.

On macOS, XGBoost also needs the OpenMP runtime: `brew install libomp`.
